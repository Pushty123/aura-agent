# Roadmap

**Built in base:** vault, consent, audit, ledger, 2 detectors, balance score, food parser, command parser, relay.

**Hackathon days (suggested):**
- Day 1: run on phone (Capacitor), real screen-time via native plugin, polish Today screen.
- Day 2: more detectors (caffeine→sleep, workout→mood), CSV import, nicer charts, reminder polish.
- Day 3: demo script, seed demo data, bug-bash, README screenshots, pitch.

**Later (not built; do not demo as real):** on-device LLM (WebLLM), multi-device pairing (PAKE), redaction gateway, Android Keystore hardware key, leaderboards.
